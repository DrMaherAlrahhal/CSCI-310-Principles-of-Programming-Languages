01 · Control Flow

Control flow refers to the order in which instructions are executed in a program.

It allows programmers to control how a program behaves, makes decisions and repeats tasks. 
There are three main types of control flow: 
  •  Sequential execution, where instructions are executed one after another; 
  •  Conditional execution, where decisions are made based on specific conditions using if, elif and else; and 
  •  Repetition, where instructions are repeated using for and while loops.

Sequential

x = 10
x = (x + 5) * 2
print(x)
Output / result 30

Conditional

mark = 75
if mark >= 50:
    print("Pass")
else:
    print("Fail")
Output / result Pass

Repetition

total = 0

for i in range(1, 5):
    total = total + i

print(total)
Output / result 10

02 · Control Transfer

Control transfer refers to changing the normal order of instruction execution in a program. 

It allows programmers to skip instructions, terminate loops, exit functions or jump to another location in the program. 
Common control transfer statements include:
  • break, which terminates a loop completely; 
  • continue, which skips the current iteration and moves to the next one; 
  • return, which terminates a function and optionally returns a value; and 
  • goto, which transfers execution directly to a labelled statement in languages such as C.

Break

for i in range(1, 6):
    if i == 3:
        break
    print(i)
Output / result 1 2

Continue

for i in range(1, 6):
    if i == 3:
        continue
    print(i)
Output / result 1 2 4 5

Return

def check(mark):
    if mark >= 50:
        return "Pass"
    return "Fail"
print(check(80))
Output / result Pass

Goto (C)

#include <stdio.h>
int main() {
    puts("Start");
    goto end;
    puts("Processing");
end:
    puts("Finish");
    return 0;
}
Output / result Start Finish

03 · Programming Errors

Programming errors are mistakes in a program that prevent it from running correctly or producing the expected results. 

There are three main types of programming errors: 
  • syntax errors, which occur when the code violates the grammatical rules of a programming language, such as a missing colon in Python; 
  • runtime errors, which occur during program execution, such as dividing a number by zero; and 
  • logical errors, which occur when a program runs successfully but produces incorrect results due to incorrect logic, such as using addition instead of multiplication to calculate the area of a rectangle.

Syntax

if 10 > 5
    print("Hello")
Output / result SyntaxError: missing colon

Runtime

print(10 / 0)
Output / result ZeroDivisionError

Logical

length = 10
width = 5
print(length + width)
Output / result 15 (incorrect area; correct area is 50)

04 · Exception Handling

Exception handling is a programming mechanism used to detect and manage unexpected errors that occur during program execution. Instead of allowing a program to crash, exception handling enables programmers to respond to errors in a controlled manner. 


In Python, the try block contains instructions that may cause an exception, while the except block handles specific exceptions when they occur.

Unsafe

number = 0
print(100 / number)
print("Done")
Output / result ZeroDivisionError

Safe

try:
    number = int(input("Enter number: "))
    print(100 / number)
except ZeroDivisionError:
    print("Cannot divide by zero")
except ValueError:
    print("Invalid input")
print("Program completed")
Output / result Input 0: Cannot divide by zero; Program completed

05 · Python Exception Keywords

Exception handling keywords are special instructions used to manage errors and control program execution when unexpected situations occur. 

Python provides five important keywords: 
  • try, which contains code that may cause an exception; 
  • except, which handles a matching exception; 
  • else, which executes when the try block completes successfully without an exception; 
  • finally, which executes when leaving the statement, regardless of whether an exception occurs; 
  • and raise, which allows programmers to generate an exception manually.

Complete example

try:
    n = int(input("Number: "))
    result = 100 / n
except ZeroDivisionError:
    print("Cannot divide by zero")
except ValueError:
    print("Invalid input")
else:
    print("Result:", result)
finally:
    print("Program completed")
Output / result Input 5: Result: 20.0; Program completed

06 · Common Python Exceptions

Common Python exceptions are predefined error types that occur when a program encounters an invalid operation during execution. 

Python provides several built-in exceptions, including 
  • ZeroDivisionError, which occurs when dividing a number by zero; 
  • ValueError, which occurs when an operation receives an inappropriate value, such as converting "Hello" into an integer; 
  • TypeError, which occurs when incompatible data types are used together, such as adding an integer to a string; 
  • IndexError, which occurs when accessing an element outside the valid range of a list; and 
  • FileNotFoundError, which occurs when attempting to open a file that does not exist.

Multiple handlers

numbers = [10, 20, 30]
try:
    index = int(input("Index: "))
    print(numbers[index])
except ValueError:
    print("Invalid input")
except IndexError:
    print("Invalid index")
Output / result Input 5: Invalid index

07 · Raising Exceptions

Raising exceptions is a programming technique that allows programmers to manually generate an exception when a specific condition or invalid situation occurs. 

In Python, the raise keyword is used to trigger an exception, while the except block is used to catch and handle it. 

Unlike built-in exceptions that occur automatically during invalid operations, raising exceptions allows programmers to define their own validation rules. 
  • For example, in a student grading system, if a user enters a mark below 0 or above 100, the program can use raise ValueError("Invalid mark") to reject the input and display an appropriate error message. 
Raising exceptions helps enforce application rules, prevent invalid data processing and improve program reliability.

Validate marks

try:
    mark = int(input("Mark: "))
    if not 0 <= mark <= 100:
        raise ValueError("Invalid mark")
    print("Valid mark:", mark)
except ValueError as error:
    print(error)
Output / result Input 120: Invalid mark

08 · Real-Life Applications

Apply exception handling to banking, login and shopping. These are simplified classroom examples, not production systems.

ATM

balance = 1000
try:
    amount = int(input("Amount: "))
    if amount <= 0:
        raise ValueError("Amount must be positive")
    if amount > balance:
        raise ValueError("Insufficient balance")
    balance -= amount
    print("Remaining balance:", balance)
except ValueError as error:
    print(error)
finally:
    print("Thank you")
Output / result Input 200: Remaining balance: 800; Thank you

Login

try:
    password = input("Password: ")
    if password != "1234":
        raise ValueError("Incorrect password")
    print("Login successful")
except ValueError as error:
    print(error)
finally:
    print("Login process completed")
Output / result Input 1234: Login successful; Login process completed

Discount

price = 200
try:
    discount = int(input("Discount: "))
    if not 0 <= discount <= 100:
        raise ValueError("Invalid discount")
    print("Final price:", price - price * discount / 100)
except ValueError as error:
    print(error)
