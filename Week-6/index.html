Lab 2 · Inductive data types

Build large structures from small ones

An inductive (recursive) type has a base case and one or more constructors that use smaller values of the same type.

List = Empty | Node(value, List)
Example: Node(10, Node(20, Node(30, Empty)))

Lab 4 · Abstract syntax

Look at program meaning, not punctuation

An Abstract Syntax Tree (AST) stores essential structure such as operations and operands, not every punctuation token.

Predict the result
Why do 2 + 3 * 4 and (2 + 3) * 4 produce different results?
They have different tree structures. Multiplication is deeper in the first expression; addition is deeper in the second.


Lab 5 · Data abstraction
Use an interface; hide the representation
A stack provides push, pop and peek. Users should not need to know how its internal storage works.
interface Stack:
    push(item)
    pop()
    peek()
    isEmpty()

Implementation can change without changing the interface.
