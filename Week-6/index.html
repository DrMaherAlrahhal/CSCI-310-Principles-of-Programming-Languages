1 · Aggregate Data Types

Keep related information together.

Meaning: An aggregate data type stores several values as one organized collection. Instead of creating a separate variable for every mark or student detail, group the values.
List / Array

Many values in an ordered collection, accessed by numeric index starting at 0. Python lists can change.

marks = [72, 85, 91, 66]
print(marks[1])  # 85
Tuple

Values stored in fixed positions. A Python tuple cannot have its elements reassigned.

point = (4, 7)
print(point[0])  # 4
Record / Dictionary

Related fields identified by meaningful names (keys).

student = {"name":"Sara",
           "id":101,"gpa":3.5}
print(student["name"])  # Sara
List of Records

Store multiple students and select a record before selecting a field.

students = [
 {"name":"Sara","gpa":3.5},
 {"name":"Omar","gpa":3.8}
]
print(students[1]["name"]) # Omar

Real situation: A teacher needs marks for 20 students, plus each student's name, ID, and GPA.

2 · Inductive Data Types

Build a larger structure from smaller parts.

Inductive means building something larger from smaller pieces, step by step. An inductive data type is defined using a base case and a recursive constructor.
Part 1 · Base case

The simplest possible structure. For a list, the base case is Empty. It stops recursion.

Part 2 · Recursive constructor

Node(value, rest) adds one value in front of a smaller list.

Build a list step by step

Empty
Node(30, Empty)
Node(20, Node(30, Empty))
Node(10, Node(20, Node(30, Empty)))

Here, value is the current number, and rest is the remaining smaller list.

Python example · Recursive sum

def total(items):
    if not items:       # base case
        return 0
    return items[0] + total(items[1:])

print(total([2, 4, 6]))  # 12

3 · Variant Records

One kind of value, different valid forms.

Variant means a different form or version. A variant record can represent one of several possible forms of information. A tag identifies which form is active; fields store its details.
Tag (type)Relevant field
CardLast four digits
CashAmount
BankReference number
payment = {"type": "Card", "last4": "1234"}

if payment["type"] == "Card":
    print(payment["last4"])  # 1234

Remember: Check the tag first, then read only fields belonging to that variant.

4 · Abstract Syntax Trees (AST)

Show how a program expression is structured.

Abstract: only important parts. Syntax: expression structure. Tree: parent and child nodes. An AST represents operators and operands in a tree, leaving out unnecessary punctuation.
Root node

The operator performed last.

Child and leaf nodes

Children are connected subexpressions; leaves are numbers or variables.

Explore five expressions

2 + 3

How to draw an AST

  1. Find the operator evaluated last: this is the root.
  2. Place its operands or subexpressions below it.
  3. Repeat for each subexpression.
  4. Put numbers or variables at the leaves.

Important: Evaluate the child expressions first, then the root operation.

5 · Data Abstraction

Use an interface without exposing the inside.

Abstraction means hiding unnecessary details and showing only what the user needs. Example: an ATM lets you withdraw, deposit, or check a balance without showing the bank's internal processing.
Interface (What)

The operations users are allowed to perform.

Implementation (How)

The internal code and data structures that make the operations work.

Stack example · LIFO

A stack follows Last In, First Out.

OperationMeaning
push()Add an item on top
pop()Remove and return the top item
peek()View the top item without removing it

Try the stack operations

Top item: 30

Use the interface without needing to see how the values are stored.

Python example

class Stack:
    def __init__(self):
        self._items = []
    def push(self, item):
        self._items.append(item)
    def pop(self):
        return self._items.pop()
    def peek(self):
        return self._items[-1]

s = Stack()
s.push(10)
s.push(20)
print(s.peek())  # 20
print(s.pop())   # 20

Key idea: Users call push(), pop(), and peek() without knowing whether the stack uses an array or linked list internally.
