SECTION 1

Local Binding — let

1. Main Ideas

Local: Exists only inside a specific part of a program.

Binding: Connecting a variable name to a value.

let: A Scheme keyword used to create local bindings.

Local binding gives variables temporary values that can be used inside a limited part of the program without changing unrelated variables.

2. Parts of let

  1. Keyword: let begins the local binding.
  2. Bindings: Give names their initial values.
  3. Body: Uses those variables to calculate a result.
(let ((variable1 value1)
      (variable2 value2))
  expression)

SECTION 2

Conditional Evaluation — if and cond

1. Main Ideas

Conditional evaluation allows a program to choose what to calculate based on a test.

if: Selects between two alternatives.

cond: Selects the first matching branch from several alternatives.

TermMeaning
ConditionA test that produces true or false
#tTrue
#fFalse
ifChoose one of two branches
condChoose the first matching branch
elseFallback branch

2. Using if

(if condition
    expression-if-true
    expression-if-false)
  1. Evaluate the condition.
  2. Choose the true branch if the condition is true.
  3. Otherwise choose the false branch.
  4. Only the chosen branch is evaluated.

4. Using cond

(cond
  (condition1 result1)
  (condition2 result2)
  (condition3 result3)
  (else default-result))

Check tests from top to bottom. The first matching branch gives the result; else is the fallback.

SECTION 3

Functions — Non-recursive and Recursive

1. Main Ideas

A function is reusable code that takes inputs, performs operations, and produces a result.

  1. Name: Identifies the function.
  2. Parameters: Receive input values.
  3. Body: Performs the calculation.
  4. Return value: The result of the function.
(define (function-name parameter)
  expression)
Non-recursiveRecursive
Does not call itselfCalls itself
Calculates directlySolves smaller versions of a problem
Example: squareExample: factorial

2. Non-recursive Functions

A non-recursive function calculates without calling itself.

3. Recursive Functions

A recursive function calls itself to solve a smaller version of the same problem.

Base case: Stops recursion.
Recursive case: Calls the function on a smaller problem.

4. Visualize Factorial Recursion

Calls:
fact(4) → 4 × fact(3)
fact(3) → 3 × fact(2)
fact(2) → 2 × fact(1)
fact(1) → 1 × fact(0)
fact(0) → 1 (base case)
Returning:
fact(0) = 1 → fact(1) = 1 → fact(2) = 2 → fact(3) = 6 → fact(4) = 24
