Four criteria, four different questions

✍ Writability

How easily can we express the solution?

🛡 Reliability

Can the program behave correctly and dependably?

💰 Cost

What resources are required across the software lifecycle?

Lab 4 · Formal languages and grammar

Grammar decides which structures are valid

Python accepts mark = 75 but rejects 75 = mark. A formal language has precise rules for valid statements.

<assignment> → <variable> = <value> <variable> → x | mark <value> → 10 | 75

Nonterminals: categories such as <variable> that must be replaced. Terminals: final symbols such as mark, =, 75.
