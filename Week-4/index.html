Example lab 01

Software engineering: organize a bigger program

As programs grow, functions, modules and objects help keep them understandable, testable and maintainable.

One giant function

Harder to test or change independently.

def app(mark):
  # input, grading,
  # report, saving...
Smaller functions

Each part has one clear responsibility.

def grade(mark): ...
def report(result): ...
def save(data): ...

Example lab 02

Functional programming: build layers

Small functions can be reused to create more complex functions. Change the inputs and follow the result.

(define (square x) (* x x))
(define (sum-squares x y)
  (+ (square x) (square y)))

Example lab 04

Scope and binding: which x?

Binding: what a name refers to. Scope: where the name can be used.

x = 100

def calculate():
    x = 10
    print(x)

calculate()
Example lab 05

Static scope: trace the lexical chain

When a name is not found locally, lexical lookup follows the written nesting of scopes.

x = 100
def outer():
    x = 20
    def inner():
        print(x)
    inner()
outer()
Click Start trace to inspect which x is used.
Example lab 06

Free and bound variables

A lambda parameter is bound by that lambda. Other referenced names are free in that lambda expression and must be resolved outside it.

Syntax or semantics? Fix the code
