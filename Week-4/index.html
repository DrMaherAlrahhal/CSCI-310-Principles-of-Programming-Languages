Week 4: Programming Languages

Six concepts explained with simple definitions and examples

What will we cover this week?

We will learn how to organize programs, handle multiple tasks, and understand how variables work.

1. Software Engineering2. Concurrency3. Binding4. Scope5. Static Scope & Lexical Addressing6. Free & Bound Variables
CONCEPT 01

Software Engineering

Definition: Building and organizing software in a clear and structured way.

Example — Student grading system

def grade(mark):
    return "Pass" if mark >= 60 else "Fail"

print(grade(75))

Output: Pass

Explanation: The grade() function handles student results. We can use it for different students.

Try it: Enter a student's mark.

Remember: Organize programs into small, reusable parts.

CONCEPT 02

Concurrency

Definition: A program can handle more than one task during the same period.

Example — Downloading a file

Without Concurrency
⬇ Download file
↓
🖱 Use application

Wait for the download to finish.

With Concurrency
⬇ Download
🖱 Use app

Both tasks can make progress during overlapping periods.

Explanation: You can keep using an application while a file downloads. The tasks do not have to run at exactly the same instant.

Remember: Concurrency allows tasks to overlap.

CONCEPT 03

Binding

Definition: Connecting a name to a value or object.

Example — Variable binding

x = 10
print(x)

x = 25
print(x)

Output:
10
25

Explanation: First, x refers to 10. Later, x refers to 25.

Remember: Binding connects a name to something.

CONCEPT 04

Scope

Definition: Where a variable name can be used in a program.

Global: Defined outside a function. Local: Defined inside a function.

Example — Global and local variables

x = 100

def show():
    x = 20
    print(x)

show()
print(x)

Output:
20
100

Explanation: Inside show(), Python uses local x = 20. Outside, it uses global x = 100.

Remember: The same name can refer to different values in different scopes.

CONCEPT 05

Static Scope and Lexical Addressing

Static Scope: Finding a variable based on where functions are written inside other functions.
Lexical Addressing: Identifying which nested scope contains that variable.

Example — Nested functions

x = 100

def outer():
    x = 20

    def inner():
        print(x)

    inner()

outer()

Output: 20

Global: x = 100
outer(): x = 20
inner(): print(x) → finds x in outer()

Explanation: inner() has no local x, so Python finds x = 20 in outer(). That is one enclosing function level away.

Remember: Look in the current function first, then in its surrounding functions.

CONCEPT 06

Free and Bound Variables

Bound variable: A variable introduced as a function parameter.
Free variable: A variable used in a function but not introduced or assigned within that function.

Example — Normal Python function

y = 10

def add(x):
    return x + y

print(add(5))

Output: 15

VariableTypeWhy?
xBoundFunction parameter
yFree in add()Used from outside the function

Explanation: The function receives x = 5 and uses outside variable y = 10, giving 15.

Remember: Bound = introduced here. Free = referenced from outside.
