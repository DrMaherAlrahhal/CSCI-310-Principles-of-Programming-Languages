SECTION A – MULTIPLE-CHOICE QUESTIONS

Q1. Which programming paradigm mainly uses functions and expressions?

A. Imperative programming
B. Functional programming
C. Object-oriented programming
D. Logic programming

Correct Answer: B. Functional programming

Explanation: Functional programming focuses on evaluating functions and expressions to produce results. For practiceple, Scheme uses expressions such as (+ 5 3) to calculate values.

Q2. Which programming paradigm organises programs using objects containing data and methods?

A. Functional programming
B. Logic programming
C. Object-oriented programming
D. Declarative programming

Correct Answer: C. Object-oriented programming

Explanation: Object-oriented programming organises software around objects that contain data and methods. For practiceple, a Student object can store a student's name and ID and provide a method to calculate a grade.

Q3. Which language evaluation criterion concerns how easily a programmer can understand code?

A. Reliability
B. Readability
C. Cost
D. Portability

Correct Answer: B. Readability

Explanation: Readability describes how easily programmers can read and understand source code. Clear names and simple structures improve readability and make programs easier to maintain.

Q4. What is binding in programming languages?

A. Deleting variables
B. Connecting a name to a value or function
C. Converting integers into strings
D. Executing two tasks concurrently

Correct Answer: B. Connecting a name to a value or function

Explanation: Binding associates a name with a value, function or another program entity. For practiceple, x = 10 binds the name x to the integer 10.

Q5. What is the main purpose of a variant record's tag?

A. To identify the active form of data
B. To sort all fields
C. To create a recursive function
D. To convert values automatically

Correct Answer: A. To identify the active form of data

Explanation: A variant record can represent different forms of information, such as a Card payment or a Cash payment. Its tag identifies the active form and determines which fields are valid.

Q6. In the expression 2 + 3 * 4, which operator is the root of the Abstract Syntax Tree (AST)?

A. *
B. +
C. 2
D. 4

Correct Answer: B. +

Explanation: Multiplication has higher precedence, so 3 * 4 is grouped first. Addition is the outermost operation, making + the root of the AST.

Q7. Which statement correctly describes lexical scoping?

A. Variables are always taken from the calling function
B. Variables are resolved according to where functions are defined
C. All variables must be global
D. Variables cannot have the same name

Correct Answer: B. Variables are resolved according to where functions are defined

Explanation: Lexical scoping determines variable access using the structure of the source code. An inner function can access variables from its enclosing function.

Q8. Which Scheme keyword creates local bindings?

A. print
B. cond
C. let
D. define

Correct Answer: C. let

Explanation: The Scheme keyword let creates local variables that are available inside its body. These bindings allow temporary calculations without changing unrelated outer variables.

SECTION B – CODE ANALYSIS

Q1. Binding Techniques

Consider the following conceptual callback practiceple:

# DEFINE
x = 10
y = 20

def calculate():
    print(x + y)

# EXECUTE
def execute(func):
    x = 50
    y = 60
    func()

# PASS
x = 30
y = 40
execute(calculate)

a. Calculate the result under each of the following conceptual binding techniques.

Answer:

Binding technique Environment used Calculation Result
Ad-hoc binding DEFINE 10 + 20 30
Deep binding PASS 30 + 40 70
Shallow binding EXECUTE 50 + 60 110

Explanation:

  • Ad-hoc binding: Uses the environment associated with the function's definition.
  • Deep binding: Uses the environment associated with passing the function.
  • Shallow binding: Uses the environment where the function is executed.

These are the conceptual binding cases used in the course material. They are not three selectable execution modes in Python.

b. Write the actual Python output.

Answer:

70

Step-by-step explanation:

  1. Initially, the global variables are x = 10 and y = 20.
  2. Before calling execute(calculate), the global variables change to x = 30 and y = 40.
  3. Inside execute(), the variables x = 50 and y = 60 are local to that function.
  4. The function calculate() reads the global variables, not the local variables inside execute().
  5. Therefore, Python calculates 30 + 40 = 70.

Explanation: Python uses lexical scoping. The conceptual binding comparison must be distinguished from actual Python execution.

Q2. Local Binding in Scheme

Consider the following Scheme expression:

(let ((x 10))
  (let ((x 2)
        (y (+ x 3)))
    (+ x y)))

a. Write the exact output.

Answer:

15

b. Explain which value of x is used to calculate y and why.

Answer:

The expression used to calculate y takes the outer value x = 10.

Therefore:

Outer x = 10

Inner x = 2

y = 10 + 3 = 13

Final result = 2 + 13 = 15

Step-by-step explanation:

  1. The outer let creates x = 10.
  2. The inner let creates new bindings for x and y.
  3. In ordinary Scheme let, the initial values are evaluated in the surrounding environment.
  4. Therefore, y uses the outer x = 10, giving y = 13.
  5. Inside the inner body, the new x = 2 is used.
  6. The final expression becomes (+ 2 13), producing 15.

Explanation: Ordinary let evaluates binding expressions before the new local bindings become available in its body.

Q3. Conditional Evaluation

Consider the following Scheme expression:

(let (( 78)
      (attendance 85))
  (cond
    ((< attendance 75) "Not Eligible")
    ((>=  90) "Excellent")
    ((>=  60)
     (if (>= attendance 80)
         "Pass"
         "Review"))
    (else "Fail")))

a. Write the exact output.

Answer:

"Pass"

b. Explain which conditions are evaluated and why the selected branch produces that output.

Answer:

Step Condition Result
1 85 < 75 False
2 78 >= 90 False
3 78 >= 60 True
4 85 >= 80 True
5 Selected result "Pass"

Step-by-step explanation:

  1. let creates = 78 and attendance = 85.
  2. The first cond condition is false because attendance is not below 75.
  3. The second condition is false because the is below 90.
  4. The third condition is true because the is at least 60.
  5. The nested if checks whether attendance is at least 80.
  6. Since 85 >= 80 is true, the expression returns "Pass".

Explanation: cond selects the first matching branch, while if chooses between two alternatives.

Q4. Type Conversion and Coercion

Consider the following Python program:

x = int("8")
y = 2.5

print(x + y)
print(int(9.8))

a. Write the exact output of both print statements.

Answer:

10.5
9

b. Explain the type conversions or coercions performed in the program.

Answer:

  • int("8") explicitly converts the string "8" into the integer 8.
  • 8 + 2.5 produces the floating-point value 10.5 through automatic numeric coercion.
  • int(9.8) explicitly converts the floating-point value into the integer 9, discarding its fractional part.

Step-by-step explanation:

  1. Python converts "8" into the integer 8.
  2. When adding 8 and 2.5, Python produces a floating-point result.
  3. The first print statement displays 10.5.
  4. The second conversion truncates 9.8 towards zero, producing 9.

Explanation: Explicit conversion is requested by the programmer, while coercion happens automatically during an operation.

SECTION C – SHORT-ANSWER QUESTIONS

Q1. Programming Paradigms

Question: Explain the difference between imperative programming and functional programming. Give one simple practiceple of each.

Answer:

Imperative programming describes how to solve a problem through a sequence of instructions that can change program state.

practiceple:

x = 5
x = x + 3
print(x)

Output:

8

Functional programming focuses on evaluating functions and expressions to produce results.

practiceple in Scheme:

(+ 5 3)

Result:

8

Comparison:

Imperative programming Functional programming
Focuses on instructions Focuses on functions and expressions
Commonly changes variables Often emphasises avoiding mutable state
practiceple: Python assignment practiceple: Scheme expressions

Concept explanation: Imperative programming describes the steps used to perform a calculation. Functional programming expresses the calculation through function application.

Q2. Scope and Binding

Question: Explain the difference between global scope and local scope. Use a simple Python practiceple to support your answer.

Answer:

Global scope: A variable defined outside functions belongs to the module's global scope.

Local scope: A variable defined inside a function is normally available only within that function.

practiceple:

x = 100

def show():
    x = 20
    print(x)

show()
print(x)

Output:

20
100

Step-by-step explanation:

  1. The global variable x is assigned 100.
  2. Inside show(), a separate local variable x is assigned 20.
  3. The first print() uses the local variable and displays 20.
  4. The second print() uses the global variable and displays 100.

Explanation: Local variables can shadow global variables with the same name without changing the global value.

Q3. Data Types

Question: Explain the differences between a list, tuple, dictionary and list of records. Give one suitable application for each.

Answer:

1. List

A list stores an ordered collection of values and allows elements to be modified.

 = [72, 85, 91]
print([1])

Output: 85

Application: Storing student .

2. Tuple

A tuple stores an ordered collection whose elements cannot be reassigned after creation.

point = (4, 7)
print(point[0])

Output: 4

Application: Representing a fixed coordinate (x, y).

3. Dictionary

A dictionary stores information using named keys.

student = {
    "name": "Sara",
    "id": 101,
    "gpa": 3.5
}

print(student["name"])

Output: Sara

Application: Storing the information of one student.

4. List of records

A list of records stores several structured entries, each containing multiple fields.

students = [
    {"name": "Sara", "id": 101},
    {"name": "Omar", "id": 102}
]

print(students[1]["name"])

Output: Omar

Application: Storing information about many students.

Concept explanation: Lists and tuples access values using positions, while dictionaries access values using named keys. A list of dictionaries combines both ideas to organise multiple structured records.

SECTION D – APPLIED PROBLEMS

Q1. Binary Search Tree (BST)

Question: Construct a Binary Search Tree by inserting the following elements in order:

45, 25, 65, 15, 35, 55, 75

a. Draw the initial BST after inserting all seven elements.

Answer:

           45
         /    \
       25      65
      /  \    /  \
    15   35  55   75

Step-by-step explanation:

  1. Insert 45 as the root.
  2. Insert 25 to the left of 45 because 25 is smaller.
  3. Insert 65 to the right of 45 because 65 is greater.
  4. Insert 15 to the left of 25.
  5. Insert 35 to the right of 25.
  6. Insert 55 to the left of 65.
  7. Insert 75 to the right of 65.

b. Insert the values 30 and 60 into the BST. Draw the final tree showing their correct positions.

Answer:

             45
           /    \
         25      65
        /  \    /  \
      15   35  55   75
           /     \
          30      60

Inserting 30:

  • 30 < 45 → move left.
  • 30 > 25 → move right.
  • 30 < 35 → insert as the left child of 35.

Inserting 60:

  • 60 > 45 → move right.
  • 60 < 65 → move left.
  • 60 > 55 → insert as the right child of 55.

Explanation: In a BST with distinct values, smaller values belong in the left subtree and greater values belong in the right subtree.

Q2. Abstract Syntax Tree (AST)

Question: Consider the following expression:

(8 + 4) * (6 - 2) + 5

a. Draw the Abstract Syntax Tree.

Answer:

              +
             / \
            *   5
           / \
          +   -
         / \ / \
        8  4 6  2

Step-by-step explanation:

  1. The parentheses group 8 + 4 into one subtree.
  2. The parentheses also group 6 - 2 into another subtree.
  3. The two results are multiplied, so * connects both subtrees.
  4. Finally, 5 is added, so the outermost + becomes the root.

b. Calculate the final result.

Answer:

(8 + 4) * (6 - 2) + 5
= 12 * 4 + 5
= 48 + 5
= 53

Final result: 53

Explanation: An AST represents the structure of an expression and makes the order of operations clear.

Q3. Inductive Data Types

Question: Consider the following recursive list representation:

Node(10, Node(20, Node(30, Empty)))

a. Identify the base case.

Answer: Empty

Explanation: Empty represents the simplest possible list, containing no elements. It ends the recursive construction.

b. Identify the number of nodes and write their values in order.

Answer:

Number of nodes: 3

Values in order:

10 → 20 → 30 → Empty

Explanation: Each Node stores one value and a reference to the remaining list. The representation contains three nodes before reaching Empty.

c. Explain the purpose of Node(value, rest) in an inductive data type.

Answer:

Node(value, rest) constructs a list element using two parts:

  • value: The current element.
  • rest: The remaining list, which can contain more nodes or Empty.

practiceple:

Node(10, Node(20, Empty))

This represents a list containing 10 followed by 20.

Explanation: An inductive data type is built from a base case and constructors that combine smaller values into larger structures.

EXTRA PRACTICE – LISP / SCHEME

Question: Write the exact result of each Scheme expression.

(car '(10 20 30))

(cdr '(10 20 30))

(cons 5 '(10 20))

Answer 1

(car '(10 20 30))

Result:

10

Explanation: car returns the first element of a non-empty list. Here, the first element is 10.

Answer 2

(cdr '(10 20 30))

Result:

(20 30)

Explanation: cdr returns the remaining list after its first element. Removing the first element 10 leaves (20 30).

Answer 3

(cons 5 '(10 20))

Result:

(5 10 20)

Explanation: cons creates a new pair with 5 as the first element and the existing list as the remainder. This produces a new list beginning with 5.
