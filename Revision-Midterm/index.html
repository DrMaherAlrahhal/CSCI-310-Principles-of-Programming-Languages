Section A · Programming Paradigms and Language Evaluation

Q1. Programming Paradigm Analysis

Key concepts

Imperative programming — explains how to solve a problem through instructions, loops and changing variables.

Functional programming — focuses on applying functions to values and combining their results.

Worked example: To double [1, 2, 3], an imperative approach uses a loop and appends each doubled value. A functional-style approach can use map(lambda x: x * 2, numbers). Both represent the same transformation.

Python supports multiple paradigms. The questions ask which style each program illustrates, not whether Python belongs to only one paradigm.

Try it yourself

Consider the following two Python programs.

Program A
numbers = [2, 4, 6]
result = 0
for n in numbers:
    result += n
print(result)
Program B
numbers = [2, 4, 6]
result = sum(map(lambda n: n, numbers))
print(result)
  1. Identify the main programming paradigm illustrated by each program.
  2. Explain the difference between the two approaches in terms of how the result is calculated.
  3. Write the output of both programs and explain why they produce the same result.

Model answer

a. A illustrates an imperative approach; B illustrates a functional-style approach.

b. A updates result repeatedly inside a loop. B passes values through map and aggregates them with sum. The lambda is the identity function, so the original values are unchanged.

c. Both print 12 because 2 + 4 + 6 = 12.

Q2. Programming Language Evaluation

Key concepts

Readability — how easily someone can understand code.

Writability — how easily a programmer can express a solution. Shorter code may improve writability, but readability can depend on familiarity and clarity.

Worked example: total = sum([1, 2, 3]) expresses a calculation in one line. A loop shows each addition separately. Either may be easier to read depending on the audience.

Try it yourself

Program A
total = 0
for i in range(1, 6):
    total += i
print(total)
Program B
print(sum(range(1, 6)))
  1. Which program do you consider more readable? Explain your choice using the concept of readability.
  2. Compare the two programs in terms of writability. Which program requires less code, and why?

Model answer

a. A reasonable answer is Program B: sum(range(1, 6)) states the goal directly and is concise. Program A is also acceptable if justified because it makes the steps explicit.

b. Program B is more concise and requires fewer statements, because the built-in sum replaces a manually written loop. Both print 15.

Q3. Selecting Programming Paradigms

Key concepts

Imperative: a sequence of commands changes program state.

Functional: calculations are expressed through functions, often avoiding changes to existing data.

Logic: facts and rules are used to derive conclusions.

Worked example: A shopping cart that updates its running total step by step suggests an imperative approach. A function that transforms each price suggests functional style. A rule such as “eligible if credits ≥ 12” can be expressed in a logic system.

Try it yourself

A university is developing three software components:

  1. A system that updates student attendance records step by step.
  2. A system that processes a collection of marks using functions without changing the original data.
  3. A system that determines scholarship eligibility using facts and logical rules.

For each component, identify the most appropriate programming paradigm and justify your choice using one characteristic of that paradigm .

Model answer

ComponentParadigmJustification
a · Attendance updatesImperativeUses sequential instructions to update records/state.
b · Marks transformationFunctionalApplies functions without modifying original data.
c · Scholarship rulesLogicUses facts and rules to infer eligibility.

Section B · Programming Language Analysis

Q4. Syntax and Semantics

Key concepts

Syntax — the grammar of a programming language.

Semantics concerns meaning and behaviour. A statement can be syntactically valid but fail when executed due to incompatible types.

Worked example: print(2 + "4") follows Python grammar but raises a TypeError. print(2 + int("4")) prints 6.

Try it yourself

x = 5
y = "3"
print(x + y)
  1. Is the code syntactically valid? Explain your answer.
  2. Identify the error that occurs during execution and explain its cause.
  3. Correct the last statement using explicit type conversion so that the program prints 8.

Model answer

a. Yes. The code is syntactically valid Python.

b. It raises TypeError because + cannot add an integer and a string in this way.

c. Replace the last line with:

print(x + int(y))

Output: 8.

Q5. Local and Global Variables

Key concepts

A

global variable — defined outside functions. A

local variable — defined inside a function and is normally used only there. If a function assigns the same name, that local name does not automatically replace the global variable.

Worked example:
score = 80
def show():
    score = 50
    print(score)
show()
print(score)

Output: 50, then 80.

Try it yourself

x = 10

def calculate():
    x = 5
    print(x + 2)

calculate()
print(x)
  1. Write the exact output of the program.
  2. Identify the local and global variables named x. Explain why they have different values.

Model answer

a.

7
10

b. The global x is 10; the local x inside calculate() is 5. The local assignment does not change the global variable.

Q6. Local Binding in Scheme

Key concepts

Scheme's let creates temporary local bindings. In an ordinary let, the initial values are evaluated in the

surrounding environment. An inner let can introduce a new variable with the same name, hiding the outer binding inside its body.

Worked example:
(let ((x 4))
  (let ((x (+ x 2)))
    (* x 3)))

The inner x becomes 6 using outer x = 4; the final result is 18.

Try it yourself

(let ((x 10)
      (y 5))
  (let ((x (+ x 3))
        (z (+ y 2)))
    (+ x z)))
  1. Determine the value assigned to the inner x.
  2. Determine the value assigned to z.
  3. Explain which bindings are used to calculate the inner x and z.
  4. Calculate the final result.

Model answer

a. Inner x = 10 + 3 = 13.

b. z = 5 + 2 = 7.

c. The inner initialisation expressions use the outer bindings x = 10 and y = 5.

d. 13 + 7 = 20.

Q7. Abstract Syntax Tree

Key concepts

An

Abstract Syntax Tree (AST) represents the structure of an expression.

Operators are internal nodes and

numbers are leaf nodes. Parentheses and operator precedence determine the grouping.

Worked example: For 2 + 3 * 4, multiplication happens first, so + is the root and * is its right child.
    +
   / \
  2   *
     / \
    3   4

Value: 2 + 12 = 14.

Try it yourself

Consider the expression:

(8 + 4) * (6 - 2) + 5 * 3
  1. Draw the complete Abstract Syntax Tree (AST), showing the correct operators and operands.
  2. Identify the root operator and evaluate the expression.

Model answer

          +
        /   \
       *     *
      / \   / \
     +   - 5   3
    / \ / \
   8  4 6  2

Root operator: +.

Evaluation: (8 + 4) * (6 - 2) + 5 * 3 = 12 * 4 + 15 = 63.

Q8. Predict the Output

Key concepts

Conversion: int("7") becomes integer 7; int(4.9) truncates to 4.

Scope: a local variable may hide a global one.

Scheme let: inner bindings may shadow outer ones.

cond: the first true condition selects the result.

Expressions: multiplication is evaluated before addition.

Worked example:
value = "9"
print(int(value) + 2 * 3)

Convert the string first, then multiply: 9 + 6 = 15.

Try it yourself

Answer all five parts. Write the exact output or final result.

a. Type Conversion and Coercion ·
x = "12"
y = 3.5
z = int(x) + y * 2
print(int(z) - 4)
b. Global and Local Scope ·
x = 10

def calculate():
    x = 5
    y = x + 3
    print(y * 2)

calculate()
print(x + 5)
c. Scheme Local Binding and Variable Shadowing ·
(let ((a 12)
      (b 4))
  (let ((b 7))
    (+ (- a b) (* b 2))))
d. Conditional Evaluation ·
(let ((mark 75)
      (attendance 80))
  (cond
    ((< attendance 75) "Not Eligible")
    ((>= mark 85) "Excellent")
    ((>= mark 60) "Pass")
    (else "Fail")))
e. Type Conversion and Expression Evaluation ·
a = "18"
b = 4
c = int(a) / b
print(int(c) + b * 3)

Model answers · with reasoning

a. 15. Convert "12" to 12; 3.5 * 2 = 7; z = 19.0; int(z) - 4 = 15.

b. Two lines:

16
15

Inside the function, (5 + 3) * 2 = 16. Outside, global x = 10, so 10 + 5 = 15.

c. 19. Inner b = 7; (12 - 7) + (7 * 2) = 5 + 14 = 19.

d. "Pass". Attendance is not below 75, mark is not at least 85, and mark is at least 60.

e. 16. int("18") / 4 = 4.5; int(4.5) = 4; 4 + 4 * 3 = 16.
