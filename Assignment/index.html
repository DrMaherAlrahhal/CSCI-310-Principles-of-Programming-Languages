Task 1 · 5 marks · CLO2

Understand Python code

Learn these concepts before answering the programming language analysis questions.

Syntax: The rules for writing valid Python code.

Semantics: What valid code means and does when it runs.

Global variable: A name defined outside a function.

Local variable: A name created inside a function.

Scope: The part of a program where a name can be accessed.

Binding: Connecting a variable name to a value.

Conditional expression: Choosing one of two values based on a condition.

Return: Sending a result from a function back to its caller.

Separate learning example — temperature status
limit = 30

def check_temperature(temp):
    message = "Hot" if temp > limit else "Normal"
    return message

print(check_temperature(25))

Try: Find the global variable, function parameter, local variable, condition, and printed result.

Show explanation of the learning example

limit is global; temp and message are local to the function; the condition is false for 25, so the program prints Normal.

Task 2 · 9 marks · CLO3

One problem, three programming paradigms

In the official task, use marks = [85, 42, 73, 91, 55, 38, 67] and calculate the average, number passing at 50 or above, and highest mark.

Imperative programming: Tells the computer which steps to perform using loops and changing variables.

Functional programming: Uses functions and operations on collections to calculate results.

Object-oriented programming: Organises related data and operations inside a class.

Average: Sum of all marks divided by the number of marks.

Pass count: Number of marks that meet or exceed the passing threshold.

Maximum: The largest mark in the collection.

Part A — Imperative programming

Use a loop, a running total, a counter and a comparison.

Learning example — count expensive items
prices = [12, 35, 8]
count = 0
for price in prices:
    if price >= 20:
        count += 1
print(count)

Trace the loop once for each price, then adapt the idea to marks.

Part B — Functional programming

Use functions such as sum(), filter() and max() appropriately.

Learning example — select long words
words = ["cat", "computer", "book"]
long_words = list(filter(lambda w: len(w) > 4, words))
print(long_words)

filter() keeps elements that satisfy a condition; try a similar condition for passing marks.

Part C — Object-oriented programming

Store a list in an object and create methods for operations on that list.

Learning example — a simple inventory class
class Inventory:
    def __init__(self, quantities):
        self.quantities = quantities

    def total_items(self):
        return sum(self.quantities)

stock = Inventory([2, 3, 4])
print(stock.total_items())

__init__ stores object data; self refers to the current object; a method performs an operation.

How to test your own three implementations

Run each program separately; check that each produces the same three results; test with another short list; explain which statements or methods produce each result.
