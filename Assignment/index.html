What is the assignment?

In a team of 3 or 4 students only, analyse a Python program, solve problems using a range of programming paradigms, evaluate and communicate the effectiveness of your approaches, and participate in an individual technical discussion worth 5 marks.

Analyse

Syntax, semantics, names, scopes and bindings in Python.

Implement

Student-performance analysis in imperative, functional, and object-oriented styles.

Evaluate

Compare paradigms, recommend one for a university system, and explain a limitation.

Discuss individually

Run programs, explain principles and effectiveness, and describe your own contribution.

Group rule: Each group must have 3 or 4 students. Groups of 2 or 5 students will not be accepted. Each student is assessed individually during the 5-mark discussion.

Submission: 5–8 page PDF report (excluding source code and appendices), executable Python source code, program outputs and screenshots. The assessment remit specifies online submission through LMS/Turnitin and a hard copy.

Deadline: Thursday, 3 December 2026, 9:00–10:59 AM.

Task 1 · 5 marks · CLO2

Analyze Syntax, Semantics, Names, Scopes and Bindings

Study the Python program from the official assessment. Your answers should analyze the names, scopes, bindings, syntax and semantics.

Official Task 1 program
passing_mark = 50

def calculate_result(mark):
    status = "Pass" if mark >= passing_mark else "Fail"
    return status

print(calculate_result(75))

Syntax: Rules for writing valid Python code.

Semantics: What an expression or statement means when executed.

Names: Identifiers used for variables and functions.

Scope: Where a name can be accessed.

Binding: Association between a name and its value or object.

What to submit (1 mark each)

  1. Analyze the names of the global and local variables.
  2. Analyze the scope and binding of passing_mark when accessed by the function.
  3. Analyze the syntax and semantics of the conditional expression.
  4. Write the exact program output and explain its meaning.
  5. Modify the function: 85 or above → Excellent; 50–84 → Pass; below 50 → Fail.
Practice with a separate example
limit = 30

def check_temperature(temp):
    message = "Hot" if temp > limit else "Normal"
    return message

print(check_temperature(25))

Identify the global name, local names, scope, conditional expression and output. This example is for practice, not the submitted solution.

Task 2 · 7 marks · CLO3

Solve Problems Using a Range of Programming Paradigms

Working in teams, solve the same student-performance problem using imperative, functional and object-oriented programming, and communicate the effectiveness of each paradigm.

Official dataset
marks = [85, 42, 73, 91, 55, 38, 67]

Each program must calculate the average mark, number of passing students (mark ≥ 50), and highest mark.

Part A — Imperative programming 3 marks

Use loops, variables and conditional statements to solve the problem. Explain how the program processes the data.

Separate learning example: count expensive items
prices = [12, 35, 8]
count = 0
for price in prices:
    if price >= 20:
        count += 1
print(count)

Part B — Functional programming 2 marks

Use functions and appropriate operations such as map(), filter() or sum(). Explain how the functional approach differs from the imperative approach.

Separate learning example: filter long words
words = ["cat", "computer", "book"]
def is_long(word):
    return len(word) > 4
print(list(filter(is_long, words)))

Part C — Object-oriented programming 2 marks

Create a StudentPerformance class with methods for average, pass count and highest mark. Create an object and demonstrate the results.

Separate learning example: inventory class
class Inventory:
    def __init__(self, quantities):
        self.quantities = quantities

    def total_items(self):
        return sum(self.quantities)

stock = Inventory([2, 3, 4])
print(stock.total_items())
Testing tip: All three programs should produce the same results for the official dataset. Check each program and explain why its approach is effective.
Task 3 · 3 marks · CLO4

Evaluate and Communicate Programming Paradigms

Working in teams, evaluate and communicate the principles of imperative, functional and object-oriented programming by comparing your three implementations.

Readability: How easily someone can understand the code.

Writability: How easily a solution can be expressed.

Code organisation: How well related data and operations are structured.

Ease of modification: How easily features can be added or changed.

What to submit

  1. Complete a comparison table and evaluate the three paradigms with brief explanations. 1 mark
  2. Recommend the most suitable paradigm for a university system that may later include attendance, grades and student records. Justify your choice. 1 mark
  3. Explain one limitation of your recommended paradigm. 1 mark
There is no single automatic best choice: your recommendation should be supported by the features and trade-offs of your own implementations.
