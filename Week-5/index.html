1. Deep, shallow & ad-hoc binding

A callback refers to a free variable x. The answer depends on the binding convention.

Textbook dynamic-scope comparison

Deep: environment at argument passing · Shallow: environment at callback invocation · Ad-hoc: environment at function definition. These are conceptual models; Python uses lexical scoping, not these dynamic-scope choices.

2. Type checking

Static checking verifies type rules before execution; dynamic checking checks operations at runtime.

Static-style example

int age = 20;
age = "hello"; // type error

Rejected by a statically typed compiler.

Dynamic example (Python)

age = 20
age = "hello"  # allowed
age + 1  # runtime error

Reassignment is allowed; the invalid addition fails when evaluated.

3. Conversion, coercion & casting

Coercion is implicit conversion. Casting / explicit conversion requests a new type directly.

Implicit coercion

In many languages, the integer is promoted to floating point.

Explicit conversion

4. Parametric polymorphism

One generic function works for multiple types while preserving the same behavior.

function identity<T>(value: T): T {
  return value;
}
Change the type and input.
More examples: first<T>(items: T[]): T, swap<T>(a:T,b:T), List<String>, List<Integer>.

5. Operator & function overloading

One name supports different operand types or parameter signatures.

Operator +

4 + 5 → 9
"Hi" + "!" → "Hi!"

Function overload (Java)

print(int value)
print(String value)
Try changing the mode.

Function overloading is illustrated using Java-style signatures. Python does not support this signature-based overload mechanism directly.

6. Function overriding

A subclass replaces an inherited method implementation. The method chosen depends on the object's actual class.

class Animal:
    def speak(self): return "Sound"
class Dog(Animal):
    def speak(self): return "Woof"
class Cat(Animal):
    def speak(self): return "Meow"
Select an object and call its method.
Key contrast: Overloading = same name, different signatures/operand types. Overriding = subclass supplies a new implementation of an inherited method.
