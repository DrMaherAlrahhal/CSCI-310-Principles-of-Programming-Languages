1 · Data Types

💡 Main Idea

  • A type describes the kind of value stored, such as a number, text, or a collection.
  • Python identifies the type of each value automatically; use type(x) to inspect it.
  • The + operator adds numbers but joins strings: 10 + 5 is 15, while "10" + "5" is "105".
  • A list holds multiple items. Positions start at index 0, so marks[0] means the first mark.
  • Lists are mutable: updating an element changes the list. Two names can refer to the same list.

💻 Example A — Number vs String

x = 10
y = "10"
print(x + 5)
print(y + "5")

Output: 15 and 105

The first line adds numbers; the second joins text.

Show answer and explanation

72 — both operands are strings, so + joins text.

y = 4

int(x) converts text to a number. Multiplying a string repeats it.

💻 Example B — Modifying a List

marks = [60, 70, 80]
marks[0] = 90
print(marks)

Output: [90, 70, 80]

Index 0 is the first element. Lists can be changed.

❓ Think & Try — Extra Question 2

If `marks = [60,70,80]`, what happens after `marks[-1] = 95`?

Show answer and explanation

The last element changes; the list becomes [60, 70, 95].

❓ Think & Try B

b.append(30)
print(a)

Show answer and explanation

[10, 20, 30]

Both names refer to the same list object.

2 · Expressions and Statements

💡 Main Idea

  • An expression calculates a value, such as 5 + 3 * 2.
  • Python follows operator precedence: powers, multiplication/division, then addition/subtraction; parentheses change the order.
  • A statement performs an action, such as x = 10 or print(x).
  • An if/else statement chooses a branch according to a True or False condition.
  • A for loop repeats instructions; range(1, 5) gives 1, 2, 3, 4, not 5.
  • Trace the variables after every iteration to understand a loop.

💻 Example A — Operator Order

x = 5 + 3 * 2
print(x)

Output: 11

Multiplication happens before addition.

❓ Think & Try — Extra Question 3

What does `print((5 + 3) * 2)` display?

Show answer and explanation

16 — parentheses force addition before multiplication.

❓ Think & Try A

x = 20 // 3 + 2 ** 3
print(x)
Show answer and explanation

14

20 // 3 = 6 and 2 ** 3 = 8; total is 14.

💻 Example B — If / Else

if mark >= 50:

💻 Example C — Loop

total = 0
for i in range(1, 5):
    total += i
print(total)

The loop adds 1 + 2 + 3 + 4.

❓ Think & Try — Extra Question 5

3 · Functions and Procedures

💡 Main Idea

  • A function is a named block of reusable instructions, defined with def.
  • A call such as square(4) runs the function with input 4.
  • return sends a result back to the caller and ends that call.
  • In square(add(2, 3)), add runs first; then square receives its result.
  • Recursion means a function calls itself; a base case stops the repeated calls.
  • Each function call has its own local variables while it is running.

💻 Example A — Square

def square(n):
    return n * n
print(square(4))

Output: 16

4 enters the function; 4 × 4 is returned.

❓ Think & Try — Extra Question 6

What is `square(6)`? What does `return` do?

Show answer and explanation

36 — return sends 36 back to the caller.

❓ Think & Try A

def f(x):
    return x + 2

def g(x):
    return x * 3

print(f(g(f(2))))
Show answer and explanation

14

Inner f(2)=4, then g(4)=12, then f(12)=14.

💻 Example B — Nested Calls

def add(a, b):
    return a + b

def square(n):
    return n * n

print(square(add(2, 3)))

Output: 25

add returns 5 first; square then returns 25.

❓ Think & Try — Extra Question 7

What is `square(add(1, 4))`? Which function runs first?

Show answer and explanation

25 — add(1,4) returns 5 first, then square(5) returns 25.

💻 Example C — Recursion

Recursion means a function calls itself. A base case stops the calls.

def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)

print(factorial(3))

Output: 6

3 × 2 × 1 = 6.

❓ Think & Try — Extra Question 8

What does `factorial(0)` return? Why must this case exist?

Show answer and explanation

1 — it is the base case that stops recursion.

❓ Think & Try B

What happens if we remove the base case from the factorial function?

Show answer and explanation

The function keeps calling itself until Python reaches its recursion limit and raises RecursionError.

4 · Variable Scope and Environments

💡 Main Idea

  • Scope tells us where a variable name is available and which value it refers to.
  • A global variable is defined outside functions; a local variable is defined inside a function.
  • If a function creates a local x, it normally hides (shadows) the global x inside that function.
  • A function can read an enclosing variable when no nearer local variable uses the same name.
  • To trace scope, look for the closest binding in the function, then enclosing functions, then global scope.

💻 Example A — Local vs Global

x = 10

def f():
    x = 20
    print(x)

f()
print(x)

Output: 20, then 10

The function prints its local x; the final line prints the global x.

❓ Think & Try — Extra Question 9

If the global `x = 10` and the local `x = 20`, what prints inside and outside?

Show answer and explanation

Inside: 20. Outside: 10. The local name shadows the global name.

❓ Think & Try A

x = 5

def outer():
    x = 10
    def inner():
        x = 15
        print(x)
    inner()
    print(x)

outer()
print(x)

Predict all three outputs and explain which variable is used.

Show answer and explanation
15
10
5

inner uses its local x; outer uses its local x; the main program uses the global x.

💻 Example B — Enclosing Scope

x = 100

def outer():
    x = 20
    def inner():
        print(x)
    inner()

outer()

Output: 20

inner reads the nearest enclosing x.

❓ Think & Try — Extra Question 10

If the outer function sets `x = 30`, what will `inner()` print?

Show answer and explanation

30 — inner reads the variable in its enclosing function.

❓ Think & Try B

x = 10

def f():
    x = 5
    return x + 2

print(f())
print(x)
Show answer and explanation
7
10

The local x is 5, so the function returns 7. The global x remains 10.
